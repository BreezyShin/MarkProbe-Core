# Commons Mini Dataset

Small image-only validation set for MarkProbe-Core. Images are resized to at most 768 px and encoded as JPEG.

Each image title, source page, author, license, and license URL is listed in `manifest.csv`. The set only includes Commons metadata labeled CC BY 4.0, CC0, or Public domain. Retain attribution and comply with each individual license when redistributing.

Downloaded from Wikimedia Commons with the Wikimedia API.
